# Contribucions

El projecte està publicat amb llicència EUPL 1.2 i prové d'una reconstrucció funcional de l'aplicació v5.1.4.

1. Crea una branca per a la teva proposta.
2. Evita canvis de comportament sense documentar-los.
3. Afegeix o actualitza proves automatitzades amb unittest.
4. Executa les proves amb Python 3.12 abans de proposar la modificació.
5. No incloguis cap clau API, canal privat ni informació de menors.
6. Obre un pull request explicant els canvis i les proves.

Les aportacions han de ser compatibles amb la llicència EUPL 1.2. Els recursos gràfics de tercers poden tenir drets separats i no s'han de pujar sense autorització.
